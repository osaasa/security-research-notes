# GoldenEye Lab：負荷生成と検知評価のレビュー

公開日: 2026-10-31 · 種別: 改修レビュー / 検証資料の記録

## 目的

既存のGo製ツールを題材に、制御した負荷の結果を記録し、WAFやSentinelの観測と照合する方法を検討した。既存ツールの改修・検証レビューとして整理し、原著者として扱わない。

## レビュー観点

- 固定ワーカープール、Context伝播、キャンセル。
- 許可対象、リダイレクト、DNS解決後の宛先。
- 設定RPSと実効RPS、遅延、失敗率。
- JSONL出力、記録欠落、終了時集計。
- User-Agent等のラベルとWAFログの照合。

## 資料の扱い

改修資料にはビルド・テスト・性能値の記載があるが、版によってRPS・並行数上限に差がある。対応する現在のコードと実行ログを今回再確認していないため、性能値や全テスト成功を確定実績として転載しない。JSONL例も生測定値とは扱わない。

## 評価指標

| 指標 | 考え方 |
|---|---|
| 再現性 | 実効RPS / 設定RPS |
| 応答 | 失敗率、ステータス分布、P50 / P95 / P99 |
| 検知率 | 検知すべき試行に対するアラート |
| 誤検知 | 正常比較条件で出たアラート |
| 検知遅延 | 閾値超過とアラート生成の時刻差 |
| 記録品質 | 欠落、時刻ずれ、Run IDによる照合 |

表は評価設計であり数値結果ではない。ツール側の完了とSOC側の検知成功を分けることを重視した。今後はコードのCommit、環境、コマンド、出力をセットで保管する。
