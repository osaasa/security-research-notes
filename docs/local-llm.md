# ローカルLLMとMCP Fetchの検証記録

対象期間: 2026-10 · 公開日: 2026-10-31 · 種別: 作業記録 / 機材検討

## 目的

API従量課金への依存を抑え、小型モデルと外部情報取得ツールの接続を理解する。大容量モデルのダウンロード、ロード成功、実用速度の推論は別の段階として扱う。

## 作業記録

| 項目 | 内容 |
|---|---|
| 実行環境 | WindowsのOllama |
| 小型モデル | Qwen3の4B系GGUF量子化モデルを取得 |
| 設定 | Q4_K_M、コンテキスト4096を試行 |
| 軽量化 | 思考出力を抑える設定を試し、体感の重さを評価 |
| MCP Fetch | Python環境に導入し、技術記事の取得・要約を試行 |
| 他ツール | HexStrike-AI用の仮想環境を作成し起動ログを確認 |

モデル名の表現だけで安全性や回答品質を保証しない。外部ページの取得と要約の正確性も別に確認する。

## 未測定の範囲

tokens/s、初回応答時間、最大メモリ、消費電力、同条件でのモデル比較はこの版にない。「重い」という感想を定量性能として掲載しない。

大規模モデルの取得・保存は推論成功の実績ではない。DGX Spark、Ryzen AI Max搭載機、Mac等は購入比較対象であり、この記録の時点で専用機を購入済みとは扱わない。

## 次の比較

同じ質問・入力長・コンテキスト長・量子化条件・バックグラウンド負荷で測る。速度に加え、MCPで得た内容と回答の出典一致、誤り、失敗時の表示を確認する。
