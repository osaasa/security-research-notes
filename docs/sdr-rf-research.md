# SDR / RFセキュリティ：GNSS・TEMPEST研究ノート

公開日: 2026-10-31 · 種別: 本人申告 / 調査 / 測定計画

## 研究の軸

SDRで電波と受信機の振る舞いを理解し、GNSSの異常検知と電磁波漏洩を評価することに関心がある。RTL-SDR v3、HackRF One、PortaPack H2を所有し、シールドルーム内での実験を前提としている。

このノートは経験と研究内容を整理し、追試可能な記録に必要な項目を示す。測定ログがない部分に成功率・精度・到達距離の数値を補っていない。

## 機材と状態

| 機材 | 扱い |
|---|---|
| RTL-SDR v3 | 所有。受信・スペクトラム観測の機材 |
| HackRF One | 所有。RF実験の対象 |
| PortaPack H2 | 所有。HackRFと組み合わせる機材 |
| USRP B210 / Z7SDRLite等 | 比較・検討対象。導入・検証済みとは記載しない |

個々の試行のアンテナ、減衰器、ケーブル、ソフトウェア版、受信機型番はこの資料では特定できていない。機材の一般性能を本人の測定結果に置き換えない。

## GNSS：経験と未収録の結果

Cold-start spoofingの実験経験はあるが、本人申告として扱う。この公開版では対応する受信ログ、RF条件、試行回数、独立した位置・時刻基準を確認・添付していない。特定受信機への有効性や再現可能な成功実績としては提示しない。

RAIM、OSNMA、干渉・欺瞞検知、LEOによる検知・補完も調査テーマ。特定試行をこれらの機能が検知・防止したという測定結果は未収録。

### 次の測定で残すもの

| 観点 | 記録項目 | 目的 |
|---|---|---|
| 正常状態 | 位置・時刻、fix、衛星数、可能ならC/N0 | 比較基準 |
| 初期状態 | Cold / Warm start、再起動、保持データ | 条件差の分離 |
| 時刻 | UTC、受信機時刻、収集時刻 | 条件変更と状態変化の相関 |
| 環境 | シールド、結線、減衰量、基準信号 | 再現性 |
| 判定 | 偏差、fix喪失、警告、復帰 | 見た目以上の判断 |
| 試行 | 試行数、失敗例 | 1回の観測から一般化しない |

表は測定設計であり取得済みデータではない。送信・妨害用コードや波形は収録していない。

## TEMPEST・電磁波漏洩

ディスプレイ等の漏洩信号と、画面内容・接続方式・配置による違いを調査している。参考資料の閲覧と、本人の復元実験成功は別に扱う。この版に画像復元・文字認識率・復元距離の実測はない。

自己所有の表示機器で識別用パターンを表示し、条件を変えたときの観測を比較する評価を考えている。信号が見える、周期性が見える、画像が復元できる、文字が読める、という段階を分ける。

## AIの寄与

AIは仮説、機材比較、ログの読み方、記録の構造化を支援する。測定した事実や検知結果をAIの文章だけで作らない。本記事もAI支援で編集したが、RF機器の自動制御や測定値生成を行ったわけではない。

## 次の作業

[観測記録テンプレート](../templates/rf-observation.md)に機材・版・時刻・条件・判定・生ログのハッシュを残す。受信観測と正常状態から始め、条件を1項目ずつ変えて比較する。未取得の欄は推定で埋めない。

現時点の公開成果は研究内容と評価設計の整理。定量測定結果の追加は残作業である。
